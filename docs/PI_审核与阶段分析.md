## 本轮证据支持什么

P0 的 16 个配置全部通过实现验收，P1 的 16 个配置各完成 3 个完整 epoch。独立核对了每轮样本数、真实 optimizer 更新数、尾批保留、最高验证准确率选模及并列取较早 epoch 的规则。四策略的初始分类头和每轮 sampler hash 一致，每种策略在两张物理卡上各运行两组。原始证据见[审计记录](../records/acceptance_audit.json)及[验收回执](../reports/P0_P1_验收回执.md)。

LP 的主干参数和 BN buffers 固定；Adapter 原主干固定、新模块有效更新。Adapter 初始恒等、真实累积尾窗口、persistent worker 随机性以及两种骨干的恢复轨迹均有运行证据。所有 P1 参数整数与相应 P0 记录一致。

本轮观察到的是短程工程可运行性。所有配置仍在五轮 warmup 的前三轮，只有一个 profile seed；不能据此比较最终收敛、做五种子推断、断言方法优越，或证明长期数值稳定。测试集只在 P0 做完整性/结构检查，没有计算模型测试成绩。

## 数据与比较边界

训练/验证索引不重叠，官方测试来源独立。精确像素审计发现 CIFAR-100 有 26 组重复，其中 14 组跨分配后的集合；SVHN 有一组重复且无跨集合重复。按合同保留官方样本及冻结划分，未因观察到重复而修改数据。应公开这一局限，不能宣称样本像素完全独立。

R50 使用 `resnet50.a1_in1k`，ViT 使用 `vit_base_patch16_224.augreg_in21k`。架构、预训练来源、参数规模和骨干标准化共同变化。主实验比较的是这两个具体模型管线，不能把跨骨干差异单独归因于架构或预训练数据规模。两种 Adapter 的拓扑与容量也不同，参数效率不能代替显存、耗时或部署成本测量。
