| 比较 A−B | 五种子验证 best 差值均值 / pp | 样本 SD / pp | 描述性 95% 配对 t 区间 / pp |

五个 seed 固定为 `17, 42, 2026, 3407, 65537`。此处所有数值都在验证集上按最佳 epoch 选择过，区间仅供描述训练随机性；**严禁写成测试集显著性/优越性/等效性结论**。

CIFAR-100/ViT：Adapter 验证 93.232%，FT 93.264%；累计训练 7.811 对 10.087 GPU-hours，Adapter 约少 22.6%，可训练参数约为 FT 的 4.2%。LP 验证 87.948%，明显落后 FT；节约训练时间并非无精度代价。SVHN/R50：Scratch 96.134% 高于 Adapter 95.820% 和 FT 95.542%，故 Adapter 并非全策略最佳。ViT Scratch 在 CIFAR-100 完成全部 50 epoch 并得到验证 49.100%，不能再宣称“必然 NaN，完全不能训练”。两种模型权重的预训练来源不同，不能作纯架构因果归因。
