# P4 补充实验设计包 v1.0

## 决定

论文确认整体重写，但 P4-A/B/C 完成及科学总审查后才进入 P4-D。此包是设计，不是实验已完成证明；不启动训练、不修改服务器、不改变已封存 P3 结果。

先读 `01_P4实验设计与论文重写合同.md`。`02_P4_protocol.json` 是机器可读设置；`03_P4_run_matrix.json` 有84个计划训练/诊断工作项及80个待封存后解析的Flowers测试角色，不含虚构准确率。`04_关键复核.json` 是本轮关键数字复算；`05_设计一致性校验.json` 是静态检查。

## 使用

PI采纳协议与20 GPU-hours独立预算后，交给Codex按合同实现。C0实测不足以覆盖整个矩阵时先汇报，不删种子或方法。原工作路径不变，新增P4目录和账本，历史seal只读。不需要恢复已暂停的旧P3自动检查。

```bash
python audit_design.py
python recheck_key_claims.py
```

`audit_design.py`仅用标准库；关键数值重算脚本需要NumPy和SciPy。脚本不会联网、不会访问服务器、不会训练或生成新模型预测。附带脚本是设计验算工具，不是已验收的训练框架。

## 文档边界

P4-B为4个锚点＋8个边界LR候选，旧test对新模型关闭。P4-A将零GPU统计与有界遮挡推理分开。P4-C仅Flowers-102，8短测＋24选参＋40正式，封存后80项test。所有结果出来后再重写论文。
