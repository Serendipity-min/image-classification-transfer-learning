# P2 全候选曲线

每个配置一张三面板图：训练交叉熵、验证交叉熵、验证 Top-1。三档预注册 LR 的全部 15 个 epoch 均保留，灰带为第 13–15 轮选择窗口。

seed=123，每条曲线是单次调参实验；无平滑、插值、置信区间或测试集成绩。PDF/SVG 为可编辑矢量图，PNG 为 600 dpi 预览。
